# 老母猪出没！

[公开试玩](https://namhotse.github.io/laomuzhu-game/)

兼容电脑与手机的卡通打地鼠小游戏，包含宋小强、宋蛙蛙、乌苏老母猪BOSS。

- 60 秒挑战：限时冲分，误击宋蛙蛙扣 20 分。
- 无限模式：每 15 秒加速，首次误击宋蛙蛙可选择观看“1000 秒广告”复活一次。点击弹窗亲吻宋小强，每次减少 100 秒，并触发害羞与爱心动作；倒计时结束后保留分数、速度和场上进度原地复活。退出或关闭弹窗结束本局并返回首页，第二次误击直接结算。
- 锤子、红色人字拖、啤酒瓶可随时切换；Boss 需要连续命中 5 次。
- 两种模式分别保存最高分，记录只保存在玩家自己的浏览器。
- 结算页的“更换模式或道具”为绿色按钮，并保留结算保护，防止连点误开下一局。

## 本地运行

下载并直接打开 index.html 即可。图片、样式、脚本全部内嵌，不依赖外部服务。

电脑按空格暂停，按 1 / 2 / 3 切换道具；手机直接轻触角色。

## 更新网站

将新版单文件 HTML 替换为根目录 index.html，提交至 main 分支。GitHub Pages 从 main 分支根目录自动发布。
