# 老母猪出没！

[公开试玩](https://namhotse.github.io/laomuzhu-game/)

兼容电脑与手机的卡通打地鼠小游戏，包含宋小强、宋蛙蛙、乌苏老母猪BOSS。

- 持续游玩，没有时间上限，每 15 秒加速一次。
- 开局三颗“小心肝”：敲空坑或漏掉一个宋小强，各扣一颗并中断连击。点击草地和其他背景不扣；缩回瞬间点击同一坑，不会重复扣除。
- 每 10 连击补一颗小心肝，最多三颗；宋小强基础 +10 分，5 连击起 ×1.5、10 连击起 ×2。敲到宋蛙蛙会失败，放过它安全。
- 乌苏老母猪BOSS 每 40 秒登场，首次 8 秒，之后每次少 1 秒，最短 3 秒；每次仍需敲中 5 次，击退 +100 分。到时每少敲一次扣一颗小心肝。Boss 战中宋小强退下并停止刷新，不因此扣除；宋蛙蛙仍可能出现。
- 小心肝耗尽与误击宋蛙蛙共用每局一次复活机会。选择观看“1000 秒广告”，在弹窗亲吻宋小强，每次减少 100 秒并触发害羞动作；完成后回满三颗，保留分数、速度、场上进度与 Boss 血量，准备 3 秒后原地复活。退出或关闭弹窗结束本局并返回首页；复活后再次失败直接结算。
- 锤子、红色人字拖、啤酒瓶可随时切换。结算页保留按钮锁定与重开确认，防止连点误开下一局。
- 最高分和道具设置保存在玩家自己的浏览器，无需登录。

## 本地运行

下载并直接打开 index.html 即可。图片、样式、脚本全部内嵌，不依赖外部服务。

电脑按空格暂停，按 1 / 2 / 3 切换道具；手机直接轻触角色。

## 更新网站

将新版单文件 HTML 替换为根目录 index.html，提交至 main 分支。GitHub Pages 从 main 分支根目录自动发布。
